## Name

Tabfold

## Short description (≤132 characters)

Save tabs to free memory, then restore them later. Local-only — no accounts, no tracking.

## Detailed description

Tabfold helps when too many tabs eat your computer’s memory.

Click the Tabfold icon to save the current tab’s address, title, and icon, then close it. When you need the page again, restore it from the popup or the full library.

**Highlights**

- Safe save pipeline: write → verify → only then close
- Undo shortly after saving
- Search, groups, import/export (JSON and URL|title text)
- Hibernate tabs without closing them
- Dark mode, whitelist, local snapshots
- Everything stays on your device

**Permissions**
Tabfold asks only for storage, unlimitedStorage, tabs, favicon, and context menus — each explained in the project README. No remote code, no analytics, no alarms.
