# DESIGN.md — 視覺與動態

## 研究參考（只借鏡手法，不複製素材）

- 生產力工具的「高資訊密度 + 清楚主 CTA」：清單工具、閱讀稍後類擴充功能的 popup 節奏。
- 編輯／文件風介面：暖色紙感底、單一強調色、少陰影（對齊 minimalist-ui skill）。
- 無障礙：可見 focus ring、`prefers-reduced-motion` 全面關閉動畫。

## 設計系統

| Token | 值                                                               |
| ----- | ---------------------------------------------------------------- |
| 背景  | `#F7F6F3` / 深色 `#1A1B1A`                                       |
| 文字  | `#2F3437`                                                        |
| 次要  | `#5C5B58`（小字 ≥4.5:1 on `#F7F6F3`）；深色 `#B0AFA8`            |
| 強調  | `#1F6C9F` + soft `#E1F3FE`                                       |
| 字體  | IBM Plex Sans／Mono（系統後備），避免 Inter/Roboto               |
| 圓角  | 6–8px，不用大 pill 容器                                          |
| 動效  | `cubic-bezier(0.16, 1, 0.3, 1)` 的 fold-in／列表入場；尊重減動態 |

## 圖示

- 自製「折頁＋分頁籤」記號，輸出 16/32/48/128。
- 一般：骨色底＋炭色折頁；已存（active）：炭底＋淺色折頁＋藍強調。
- 產生腳本：`npm run icons`（無第三方圖像服務）。

## 介面結構

- Popup：品牌 → 狀態橫幅（含 Undo）→ 存入／範圍 → 搜尋 → 清單 → 次要動作。
- Library：完整清單、分組還原、匯入匯出、清空。
- Settings：偏好、白名單、資料說明、快照還原、捷徑說明。
